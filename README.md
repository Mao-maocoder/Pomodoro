# 番茄钟

一个离线使用的 Windows 桌面番茄闹钟。

## 使用

- 默认专注 25 分钟、短休息 5 分钟、长休息 15 分钟；每 4 次完整专注后安排长休息。
- 中间番茄图标表示本轮完成次数，跨天和重启保留。达到目标后保持满格，下一次开始专注时清零并进入新一轮；跳过长休息也适用，暂停后继续不会清零。重新计时、切换阶段和休息结束本身不清零，今日统计独立累计。
- 需要确认放弃进度时，确认后才切换选中块。
- 点击“开始”或按空格开始计时；再次点击或按空格暂停。暂停后时间不再减少。
- 阶段结束后播放一次约 2.5 秒的提示音，显示完成提示并发送托盘通知。下一阶段需要手动开始。
- “重新计时”在尚未开始时置灰；重新计时或切换进行中的阶段需要确认。放弃的进度不计入完成统计。
- 修改设置不会改变正在进行或暂停的阶段时长，新时长用于下一阶段。尚未开始的阶段会立即显示新时长。
- 关闭窗口后，程序留在 Windows 系统托盘继续计时。点击托盘图标打开，右键菜单可暂停、继续或退出。
- 系统托盘不可用时，关闭窗口会退出；退出会保存进度。
- 顶部为自绘标题区：右上角依次为最小化、最大化/还原、关闭到托盘。拖动主界面任意非交互区域移动窗口，双击这些区域最大化/还原，拖动边缘调整大小。按钮会优先接收点击，窗口尺寸或系统缩放变化后仍会自动匹配；弹窗打开时暂停背景拖动。
- 点击“置顶”可让窗口保持在其他窗口上方。
- Windows 通知可能被“请勿打扰”等系统设置拦截；声音也受系统音量和音频设备影响。
- 睡眠或休眠前自动暂停，唤醒后手动继续。锁屏不暂停。
- 今日和最近 7 天统计仅累计完整完成的专注，跨午夜的专注归入完成当天。
- 提示音可静音、调节音量和试听。试听会按所选音量播放，即使结束提示音开关关闭。
- 铃声每次使用当前默认输出设备建立新的音频流。启动失败且尚未输出音频时最多重试一次；超过期限、睡眠或设备变化会取消旧请求，连接耳机后不会补播旧铃声，需重新点击试听。
- 铃声诊断记录写入 data/audio-log.jsonl，包含请求时间、输出设备、尝试次数、输出进度和失败原因。播放或诊断记录写入失败会在界面提示。软件输出状态不能证明扬声器或耳机实际可听，仍受 Windows 音量与设备设置影响。

快捷键：空格开始/暂停，Ctrl+R 重新计时，Ctrl+, 打开设置，Esc 关闭弹窗。

## 数据

启动、状态变化、完成和退出时保存，运行中每 10 秒保存一次。
重启后，未完成的运行阶段以暂停状态恢复；已完成阶段不会再次计数或再次提醒。
保存使用原子提交。保存失败会在界面明确提示，内存中的计时仍可继续，但未保存的修改可能在重启后丢失。
若数据损坏或格式不兼容，程序会显示错误并停止启动，保留原文件，不会覆盖或重置它。
备份时请先从托盘退出，再复制整个 data 目录。

## 源码和构建

技术栈：C++20、Qt 6.11.1、Qt Quick/QML、MSVC 2022 x64、CMake/Ninja。
编译不依赖 Python，assets 中已有提示音和图标。生成的着色器包嵌入 exe，运行程序不需要 qsb 或 Qt Creator。

- src：C++ 计时、保存、统计和 Windows 集成。
- qml：主界面。
- assets：用户提供的番茄钟图标和提示音。
- build：构建产物。
- dist：可运行的发布程序。
- data：实际用户数据。
- work：资源生成脚本、测试运行数据、验证截图等中间文件。

验证日志、截图和样本数据保存在 work 目录。
